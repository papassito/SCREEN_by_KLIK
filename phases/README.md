## 1. Propósito

La **FASE 00 — CONTRACT** tiene como objetivo establecer el marco de gobierno, reglas de integridad, y alineación técnica para el proyecto SCREEN by KLIK.

Esta fase no contiene código ejecutable. Su alcance es puramente normativo y de diseño documental.
